## Problems Solved

### 1. House Robber
- Platform: LeetCode
- Approach: Dynamic Programming
- Time Complexity: O(n)
- Space Complexity: O(1)

For each house, compare robbing it with
skipping it. Keep track of the best result
using two variables to achieve constant
extra space.

Problem:
https://leetcode.com/problems/house-robber/

### 2. Fair Rations
- Platform: HackerRank
- Topic: Greedy Algorithms
- Time Complexity: O(n)
- Space Complexity: O(1)

Distribute loaves of bread to make every
person's number of loaves even. Each
operation gives one loaf to two adjacent
people.
