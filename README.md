### 1. House Robber
- Platform: LeetCode
- Approach: Dynamic Programming
- Time Complexity: O(n)
- Space Complexity: O(1)

For each house, compare robbing it with
skipping it. Keep track of the best result
using two variables to achieve constant
extra space.

Problem:
https://leetcode.com/problems/house-robber/
