## Problems Solved

### 1. House Robber
- Platform: LeetCode
- Approach: Dynamic Programming
- Time Complexity: O(n)
- Space Complexity: O(1)

For each house, compare robbing it with
skipping it. Keep track of the best result
using two variables to achieve constant
extra space.

Problem:
https://leetcode.com/problems/house-robber/

### 2. Fair Rations
- Platform: HackerRank
- Topic: Greedy Algorithms
- Time Complexity: O(n)
- Space Complexity: O(1)

Distribute loaves of bread to make every
person's number of loaves even. Each
operation gives one loaf to two adjacent
people.

### 3. N-th Tribonacci Number
- Platform: LeetCode
- Topic: Dynamic Programming
- Languages: Python (and C++, if you've solved it in both)
- Time Complexity: O(n)
- Space Complexity: O(1)

**Approach:** Start with the base cases T(0) = 0,
T(1) = 1, and T(2) = 1. Calculate each
subsequent number by adding the previous three
values, using three variables to save space.

**Problem:** https://leetcode.com/problems/n-th-tribonacci-number/
